# 🚀 QuantumCash

QuantumCash — это мощное iOS-приложение для мониторинга криптовалютного рынка, объединяющее в себе аналитику, цены, графики, новости и пользовательскую кастомизацию.  

> ⚠️ Проект в активной разработке. Это портфолио-приложение, демонстрирующее современные подходы к разработке iOS-приложений.

---

## ✨ Основные функции

- 📈 Актуальные данные по криптовалютам
- 📰 Интеграция с новостными лентами (crypto API)
- 💬 Поддержка push-уведомлений
- 📊 Графики, тренды, индикаторы
- 🔐 Хранение пользовательских данных (CoreData + Firebase)
- ⚙️ Модульная архитектура и Swift Package Manager

---

## 🧱 Технологический стек

- **SwiftUI**
- **Combine**
- **Swift 5.9**
- **CoreData**
- **Firebase (Auth, Firestore)**
- **Swift Package Manager**
- **Fastlane** (сборка, CI, скриншоты)
- **GitHub Actions** (CI/CD pipeline)
